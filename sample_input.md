Question: What is overfitting in machine learning? (5 marks)
Model answer: Overfitting occurs when a model learns the training data too closely, including noise, so it performs well on training data but poorly on unseen data. Causes: complex model, too little data. Remedies: regularization, cross-validation, more data, early stopping, simpler model.
Student answer: Overfitting is when the model does very well on training data but fails on new data because it memorised it. It can be reduced by using more data or regularization.
